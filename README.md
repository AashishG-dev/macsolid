# MacSolid — High-Performance CAD Engine & Automated BOM Extraction

A high-performance creative engineering web experience for **MacSolid / Part Separator**, crafted with Swiss Precision CAD aesthetics, WebGL GPGPU liquid particle physics, Lenis smooth scrolling, and 60 FPS interactive 3D inspection.

---

## 🛠 Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **WebGL Particle Simulation**: WebGL2 GPGPU particles (~100k GPU particles)
- **3D Graphics**: [Three.js](https://threejs.org/)
- **Scroll & Animation**: [Lenis](https://github.com/darkroomengineering/lenis) + [GSAP ScrollTrigger](https://greensock.com/scrolltrigger/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### 3. Production Build
```bash
npm run build
```

## 📐 Key Features

- **Swiss Precision CAD Aesthetic**: Ultra-minimal light porcelain theme (`#EBE9E5`), coordinate grids, and engineering typography.
- **Dynamic GPGPU Particle Hero**: The hero CAD sculpture is simulated with ~100k interactive GPU particles that fluidly dissolve on scroll and sediment into mountain dunes at the footer.
- **Interactive 3D CAD Studio**: 6-DOF orbit viewport with live axis-aligned cross-section cut-planes.
- **Automated BOM & Format Engine**: Feature breakdown and specifications for native multi-threaded STEP/IGES assembly parsing and ERP export.
- **Curated Deployment Tiers**: Tailored edition matrix inspired by modern software licensing architectures.
